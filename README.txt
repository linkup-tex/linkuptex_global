LINK UP TEX GLOBAL — FULLY EDITABLE FREE WEBSITE

QUICK EDIT:
1. Open config.js.
2. Change companyName, phone, whatsapp, email, facebook, address and website text.
3. Products are controlled in the PRODUCTS list in config.js.
4. Add your product images inside the images folder using the names:
   hoodie.jpg
   polo.jpg
   shirt.jpg
   custom.jpg
5. Upload all files/folders to your GitHub repository.

IMPORTANT:
- This website is static and can be hosted free with GitHub Pages.
- The inquiry form opens WhatsApp using the number in config.js.
- Replace placeholder Facebook/email/phone information with your real details.
